# Surtidor

App web móvil con los precios oficiales de carburantes del Ministerio (MITECO / Minetur).

Datos en vivo desde:
https://sedeaplicaciones.minetur.gob.es/ServiciosRESTCarburantes/PreciosCarburantes/EstacionesTerrestres/

El API permite CORS y se actualiza cada media hora. Las coordenadas usan coma decimal.

Capacidades de depósito y consumos: ver `vehicles.json` (fuentes: km77.com, folletos de fabricante; el Volvo S60 2.4D es 70 l según ficha km77 y datos técnicos Volvo 2004).

Publicada en https://alodyn.github.io/Surtidor/
